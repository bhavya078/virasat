## 🏛️ Project Vision

**VIRASAT** redefines digital cultural preservation and luxury heritage tourism. Inspired by the refined aesthetics of **Apple.com**, **Airbnb Experiences**, **National Geographic**, **Google Earth**, and **UNESCO World Heritage**, it presents an uncompromising standard of digital excellence:

- **Zero Placeholders & Zero Fake Data:** Every monument, hidden gem, festival, and artisan craft contains authentic, verified field intelligence.
- **100% Authentic Real Photography:** Over 830+ unique high-resolution real photographs covering monuments, living rituals, tribes, landscapes, and culinary traditions. No AI-generated artwork or stock duplicates.
- **Sovereign Indian Political Atlas:** Grounded in Survey of India (SOI) geographic projections across all 28 States and 8 Union Territories.

## ✨ Core Pillars & Platform Modules

### 1. 🏰 50 Iconic Heritage Sites & Monuments
- **Complete Monument Portfolios:** Taj Mahal, Konark Sun Temple, Hampi, Khajuraho, Ellora Caves, Brihadeeswarar, Rani ki Vav, and 43 other national treasures.
- **Interactive Architectural Breakdown:** Dynasty lineages, architectural styles (Dravidian, Nagara, Vesara, Indo-Islamic), and stone carving mastery.
- **Binaural Audio Guides:** Synthesized meditative 432 Hz temple bells paired with Web Speech narration.
- **Google Places Stays & Dining:** Verified heritage havelis, luxury stays, and sattvic/local restaurants.

### 2. 🌲 50 Untouched Hidden Gems (`/hidden-gems`)
- **Beyond the Tourist Radar:** Mawlynnong, Ziro Valley, Gandikota, Chopta, Dzukou Valley, Dhanushkodi, Loktak Lake, Majuli, and 42 secret sanctuaries.
- **Serenity & Uncrowded Index:** Quantified serenity scoring (up to 99/100) assessing tranquility and ecological preservation.
- **Expedition Logistics (18 Metrics):** Coordinates, elevation, terrain difficulty, inner-line permit (ILP) guidance, nearest airport/rail/bus, and network connectivity.
- **8K Real Photography Gallery:** Responsive masonry visual archive with fullscreen zoom lightbox and swipe controls.

### 3. 🪔 50 Living Festivals of Bharat (`/festivals`)
- **Sacred Temporal Dimensions:** Live countdown timers synchronized to celestial and lunar muhurtas.
- **4-Phase Ritual Protocols:** Detailed step-by-step guidance from Dawn Brahma Muhurta Snan to Midday Rajbhog, Twilight Sandhya Aarti, and Midnight Vigils.
- **Sacred Prasad & Mahaprasad:** Authentic culinary offerings, festival attire dress codes, and crowd survival intelligence.

### 4. 🎭 50 Classical Cultural Traditions (`/culture`)
- **UNESCO Intangible Cultural Heritage:** Kathakali, Chhau Dance, Dhokra Metal Casting, Kalaripayattu, Madhubani Art, Pashmina Weaving, and 44 living traditions.
- **Anatomy of Technique:** 4-stage master breakdown covering raw material preparation, sacred mudras, aesthetic expressions (Navarasas), and public Arangetram.
- **Masterclass Apprenticeship Guilds:** Verified government craft emporiums, certified GI tags, and artisan homestay residencies.

### 5. 🗺️ Sovereign 36 States & Union Territories Atlas (`/states`)
- **Complete Interactive Political Map of India:** State-by-state geopolitical and cultural atlas.
- **Gastronomic Master Register:** Regional delicacies, street food capitals, and royal confectionery for every state.
- **Curated 3-Day Algorithmic Routes:** Auto-planned itineraries linked with state heritage sites and hidden gems.

### 6. 🧠 Rishi AI Trip Planner (`/ai-planner`)
- **Algorithmic Itinerary Engine:** Custom itineraries tailored to user travel style (Solo, Couple, Family, Friends, Luxury, Backpacking).
- **Comprehensive Daily Breakdowns:** Morning, afternoon, and evening timelines accounting for sunlight angles, road elevation, and local timings.
- **Transparent Budget Estimates:** Real-time breakdown of accommodation, dining, activities, and transit costs.

### 7. ⛅ Live Weather & Atmospheric Intelligence (`/weather`)
- Simulated real-time micro-climate monitoring: Temperature, humidity, wind velocity, precipitation likelihood, sunrise/sunset, and color-coded AQI badges with seasonal packing advisories.

### 8. 🔍 Global Spotlight Search (`Ctrl+K`)
- Instant keyboard-driven lookup across all 50 monuments, 50 gems, 50 festivals, 50 traditions, and 36 states with auto-completion and instant navigation.

## 🛠️ Technology Stack

- **Core Framework:** React 19 + TypeScript (Strict Mode)
- **Bundler & Build Tool:** Vite 8.3
- **Routing:** React Router v7 (`/heritage/:slug`, `/hidden-gems/:slug`, `/festivals/:slug`, `/culture/:slug`, `/state/:slug`)
- **Animation & Physics:** Framer Motion 13 + Lenis Inertial Smooth Scrolling
- **Styling:** Tailwind CSS 3.4 with custom typography and shadow tokens
- **Audio Synthesizer:** Web Audio API (432 Hz Vedic temple bell harmonics) + Web Speech API (Narration)
- **Icons & Effects:** Lucide React + Canvas Confetti

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/bhavya078/virasat.git

# Navigate into the project directory
cd virasat

# Install dependencies
npm install

# Start the Vite local development server
npm run dev
```

The application will be available at `http://localhost:5173`.

### Production Build
```bash
# Run type checks and build the production bundle
npm run build

# Preview the production build locally
npm run preview
```
